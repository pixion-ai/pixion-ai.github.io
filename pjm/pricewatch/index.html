최저가 감시 (PriceWatch)

구글 시트의 기준가를 읽어 네이버 쇼핑·다나와에서 더 싸게 파는 곳이 있는지 자동으로 찾아주는 크롬 확장 프로그램입니다.

현재 버전 v0.10.0 업데이트일 2026-09-16
다운로드 (zip)
사용 설명서 보기
  1. 위 버튼으로 zip을 받아 압축을 풉니다.
  2. 크롬 주소창에 chrome://extensions 입력 → 개발자 모드 켜기
  3. 압축해제된 확장 프로그램을 로드합니다 → 방금 푼 폴더 선택
  4. 자세한 단계와 화면 설명은 사용 설명서를 참고하세요.

이미 사용 중이시라면 — 기존 폴더 안의 파일을 모두 지우고 새 압축을 같은 폴더에 푼 뒤, chrome://extensions 에서 새로고침 버튼을 누르세요. 등록한 시트·제외어 같은 설정은 그대로 유지됩니다. 다만 폴더 이름과 위치가 바뀌면 크롬이 다른 프로그램으로 인식해 설정이 사라집니다.

업데이트 내역

v0.10.02026-09-16

  • 같은 상품이 두 곳에서 팔리는 것처럼 보이던 문제를 고쳤습니다. 네이버와 다나와를 둘 다 조회하다 보니, 실제로는 11번가 한 곳에 올라온 같은 상품이 양쪽에서 각각 잡혀 두 곳처럼 보였습니다. 이제 상품 번호를 대조해서 같은 상품이면 한 줄로 합칩니다. "기준가보다 싼 곳 7건"처럼 나오던 숫자가 실제 판매처 수와 맞습니다.
  • 들어가는 경로에 따라 가격이 다른 경우를 함께 보여줍니다. 판매처는 네이버를 거쳐 온 손님과 다나와를 거쳐 온 손님에게 서로 다른 가격을 주기도 합니다. 둘 다 실제로 살 수 있는 가격이므로, 이제 두 가격을 나란히 적고 더 싼 쪽을 기준으로 판단합니다. 실제 조회에서 네이버 가격만 봤다면 놓쳤을 위반이 23건 있었습니다. 예를 들어 MH605ST 11번가는 기준가가 1,112,840원인데, 네이버를 거치면 1,143,240원이라 정상으로 보이지만 다나와를 거치면 1,099,030원이었습니다.
  • 가격 대신 적립 포인트로 값을 깎아주는 판매처를 찾아냅니다. 판매가는 기준가에 맞춰 놓고 적립 포인트를 크게 줘서 실제로는 더 싸게 파는 곳이 있습니다. 네이버가 기본으로 주는 적립(1%)은 빼고, 판매처가 자기 돈으로 더 얹어준 포인트만 계산합니다. 그 포인트를 뺀 금액이 기준가보다 낮으면 보고서에 "포인트 반영 시 기준가 미만"으로 따로 표시합니다. 기본 적립률은 네이버 정책이 바뀔 수 있어 설정에서 고칠 수 있습니다. 다만 가격비교 묶음 안에만 있는 판매처는 네이버가 적립 정보를 주지 않아 확인되지 않습니다.
  • 가격비교 묶음에 묶여 부정확하던 가격을 실제 가격으로 바로잡습니다. 네이버 가격비교 묶음은 싼 곳 5군데까지만 보여주는데, 이 가격은 갱신이 늦어 실제와 다를 때가 있습니다. 해당되는 모델은 가격비교 페이지를 한 번 더 열어 판매처별 실제 가격과 판매처 링크를 가져옵니다. 조회 시간이 다소 늘어나므로 설정에서 끌 수 있습니다.
  • 구글 시트를 여러 개 등록해 한 번에 조회할 수 있습니다. 실행 한 번으로 등록한 시트를 전부 조회해 보고서 하나로 만들고, 어느 시트의 모델인지 표시합니다. 같은 파일의 다른 탭도 따로 등록하면 됩니다.
  • 그 밖에 · CSV를 실행 시각별 폴더에 3개로 나눠 저장 (기준가미만 / 제외어확인 / 모델별상세)
    · 조회 중 실수로 탭을 닫아도 자동으로 다시 시도 (예전에는 그 모델을 놓쳤습니다)
    · 접속이 막혔을 때 남은 대기 시간을 "3분 20초"처럼 초 단위까지 표시
    · "전시장" 같은 문구 때문에 정상 상품이 걸러지던 문제 수정
    · 조회에 걸린 시간을 "11분 22초"처럼 읽기 쉽게 표시
